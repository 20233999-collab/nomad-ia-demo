# Anthropic Frontend Design Skill Specification

## 🎨 Core Principles

### 1. Distinctive Visual Personality
- Avoid boring, boilerplate UI patterns. Give every application a distinct aesthetic voice tailored to its context (e.g. Duolingo gamified, Mondrian geometric, Slate modern).
- Use intentional typography pairings: Bold display fonts for headings paired with highly legible body fonts.

### 2. High-Contrast & Polished Components
- Ensure zero ambiguity in interactive states (`:hover`, `:active`, `:focus-visible`).
- Use crisp shadows (`0 4px 14px rgba(0, 0, 0, 0.1)`) and tactile depth.
- Incorporate subtle micro-animations for feedback (e.g. bounce on success, shake on error).
