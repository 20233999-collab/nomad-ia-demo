# Goodtaste Design Skill Specification

## 💎 Design Constraints for "Good Taste"

### 1. Reject Generic Defaults
- **Never use plain raw primary colors** (pure `#ff0000`, `#00ff00`, `#0000ff`). Always use curated HSL/HEX color systems (e.g. Duolingo vibrant tones `#78c800`, `#1cb0f6`, `#ffc800`, `#ff4b4b`).
- **Never use default browser fonts.** Use modern Google Fonts (`Nunito`, `Fredoka`, `Inter`).

### 2. Crafting Delightful Micro-Interactions
- Every interactive element (cards, buttons, icons, avatars) must react visually to hover, focus, and click states.
- Drawer sheets sliding from bottom should use elastic spring bezier transitions (`transform: translateY(...)`).
- Mascots & avatars must feel alive with subtle floating animations.

### 3. Layout Polish
- Use consistent padding scales (8px, 12px, 16px, 24px, 32px).
- Provide ample breathing room around text and titles.
- Use explicit visual badges for progress, streaks, seeds, and precision.
