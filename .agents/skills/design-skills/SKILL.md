# Design-Skills System Specification

## 🎨 System Tokens & Best Practices

1. **Color Tokens:**
   - Define all brand colors as CSS custom properties (`:root`).
   - Support dark mode overrides via `[data-theme="dark"]`.

2. **Gamification Patterns:**
   - 3D tactile buttons (`box-shadow: 0 4px 0 ...`).
   - Dynamic SVG/HTML progress bars with gloss highlights.
   - S-curve node pathing with active/locked states.
   - Victory badges with category-specific header colors.

3. **Accessibility & Usability:**
   - Minimum touch targets of 44x44px for touch screens.
   - High contrast text on all backgrounds.
